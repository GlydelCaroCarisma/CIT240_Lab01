# CIT 240 Laboratory Activity 1 – Open-Source Project Information

## Project Title

**Python Open-Source Project**

## Description

Python is a high-level, general-purpose programming language that is widely used in software development, web development, automation, artificial intelligence, data science, and education. It is an open-source project maintained by the Python Software Foundation and a large community of developers.

## Features

* Simple and readable syntax
* Open-source and freely available
* Supports object-oriented and procedural programming
* Large collection of libraries and frameworks
* Used in web development, artificial intelligence, data science, and automation
* Cross-platform compatibility

## Programming Language

The Python programming language is primarily implemented in **C** in its CPython implementation.
